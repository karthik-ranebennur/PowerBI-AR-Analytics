Power BI AR Analytics Dashboard

Project Overview

An Accounts Receivable (AR) Analytics Dashboard developed using Power BI and Oracle SQL to analyze invoices, payments, collections, outstanding amounts, overdue receivables, and customer-level performance.

The dashboard provides an interactive view of the company’s receivables position and helps identify collection trends, overdue balances, and aging-related risks.

 Tools & Technologies

* Power BI
* DAX
* Oracle SQL
* Power Query
* Excel

 Data Model

The project uses multiple business tables including:

* AR Invoices
* AR Payments
* AR Customers
* AR Employees
* AR Departments
* AR Collection Target
* Calendar

The data model was designed to support invoice, payment, customer, employee, department, and time-based analysis.

📈 Key KPIs

* Total Invoice Amount
* Total Paid Amount
* Outstanding Amount
* Collection %
* Overdue %
* Aging Analysis
* 90+ Days Outstanding
* Customer-level Receivables
* Collection Target Performance

 Key Analysis

The dashboard provides analysis of:

* Accounts receivable outstanding balances
* Paid vs outstanding amounts
* Overdue receivables
* Aging buckets
* Customer payment performance
* Collection performance
* Department and employee-level analysis
* Collection target comparison
* Time-based receivables trends

 DAX

DAX measures were created to calculate business KPIs such as:

* Total Invoice Amount
* Total Paid Amount
* Outstanding Amount
* Collection %
* Overdue %
* Aging analysis
* Target achievement

 SQL

Oracle SQL was used for data preparation, validation, aggregation, and analysis before bringing the data into Power BI.

 Business Objective

The objective of this project is to provide a clear view of accounts receivable performance and help business users monitor collections, identify overdue invoices, understand aging exposure, and track collection targets.
